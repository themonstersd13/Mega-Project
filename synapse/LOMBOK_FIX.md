# 🔧 SYNAPSE - Lombok & IntelliJ Configuration Guide

## Issue: Lombok Not Recognized in IntelliJ

If you see errors like:
```
Cannot find symbol: variable [field]
Method [getter/setter] not found
```

This means IntelliJ hasn't enabled Lombok annotation processing. Here's how to fix it:

---

## ✅ Quick Fix (Automated)

Run this PowerShell script to configure everything automatically:

```powershell
cd E:\Mega Project\synapse
.\IntelliJ-Setup.ps1 setup
```

This will:
1. ✓ Update pom.xml (change Lombok scope to `provided`)
2. ✓ Create `.idea/compiler.xml` (enable annotation processing)
3. ✓ Create `.idea/misc.xml` (configure JDK 24)

---

## 🖱️ Manual IntelliJ Configuration (if automated didn't work)

### Step 1: Invalidate IDE Cache
1. Go to **File → Invalidate Caches**
2. Click **Invalidate and Restart**
3. Wait for IntelliJ to restart

### Step 2: Enable Annotation Processing
1. Go to **Settings** (Ctrl+Alt+S on Windows)
2. Navigate to: **Build, Execution, Deployment → Compiler → Annotation Processors**
3. Enable these checkboxes:
   - ✓ **Enable annotation processing**
   - ✓ **Obtain processors from project classpath**
4. Click **OK**

### Step 3: Reimport Maven Project
1. Right-click `pom.xml` in Project Explorer
2. Select **Maven → Reload Projects**
3. Or: **File → Reload All Maven Projects**

### Step 4: Rebuild IntelliJ Index
1. Go to **File → Invalidate Caches**
2. Select **Invalidate and Restart**

## 📋 What Was Fixed

### Changes to `pom.xml`
**Before:**
```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>  <!-- ← Problem: optional scope confuses IntelliJ -->
</dependency>
```

**After:**
```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.30</version>
    <scope>provided</scope>  <!-- ✓ Tells IntelliJ it's available at compile time -->
</dependency>
```

### Created `.idea/compiler.xml`
Enables IntelliJ's annotation processor path for Lombok:
```xml
<annotationProcessing>
  <profile default="true" name="Default" enabled="true">
    <processorPath useClasspath="true" />
  </profile>
</annotationProcessing>
```

### Created `.idea/misc.xml`
Configures Java version and encoding:
```xml
<component name="ProjectRootManager" version="2" languageLevel="JDK_24" ... />
```

## 🆘 Still Not Working?

If Lombok still isn't recognized:

### 1. Check Maven Dependencies
```powershell
mvn dependency:tree | Select-String lombok
```

Should show: `org.projectlombok:lombok:jar:1.18.30:provided`

### 2. Rebuild IDE Index
1. File → Invalidate Caches → **Invalidate and Restart**
2. Wait for IDE to finish indexing (bottom right corner shows "Indexing Complete")

### 3. Delete IntelliJ Cache
```powershell
Remove-Item "$env:USERPROFILE\.IntelliJIdea*\system\caches" -Recurse -Force
```
Then restart IntelliJ.

### 4. Check Java SDK
1. **File → Project Structure** (Ctrl+Alt+Shift+S)
2. **Project** tab → Confirm SDK is "Java 24"
3. **SDKs** tab → Confirm "Java 24" path is correct

### 5. Install Lombok Plugin (Last Resort)
1. **Settings → Plugins**
2. Search for "Lombok"
3. Install the official Lombok plugin by Michał Szmigiero
4. Restart IntelliJ
